📦 Como Instalar no Eclipse IDE

1
Abra o seu Eclipse IDE (versão 2024-06 ou superior recomendada).
2
Acesse o menu: Help ➔ Install New Software...
3
Cole a URL acima no campo Work with: e pressione Enter.
4
Selecione a categoria EveryWhere Harness e conclua o assistente.
