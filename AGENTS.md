# Everywhere-DeepSeek-Harness Rules

This repository maintains the Everywhere Harness client plugins and extensions for multiple IDEs:
- **VS Code Extension** (`vscode/`)
- **Eclipse IDE Plugin & p2 Update Site** (`eclipse/`)
- **IntelliJ IDEA Plugin** (`intellij/`)
- **Visual Studio 2022 Extension** (`visualstudio/`)

## Release and Pre-Push Policy

Always follow the [ewh-multi-ide-release-validator](.agents/skills/ewh-multi-ide-release-validator/SKILL.md) skill before making commits, tags, or pushing branches:
1. Always run `python3 scripts/validate-release.py` to ensure OSGi versions, Tycho p2 repository plugins, and release workflow path matches are valid.
2. In `eclipse/pom.xml`, when version is a `-SNAPSHOT`, `eclipse/META-INF/MANIFEST.MF` must have `Bundle-Version: x.y.z.qualifier`.
3. In `.github/workflows/release.yml`, artifact and deployment upload paths must point to real output directories generated by the build.
